# The builder itself (served at /builder/, file on disk is index_1.html -
# see render.yaml routes) has no meaningful indexable content - only the
# landing page and blog are meant to show up in search results. It's
# deliberately NOT Disallow'd here though: a page blocked in robots.txt
# can never be crawled, which means Google can never see a noindex tag on
# it either - and since the homepage links to it directly ("Open the
# Builder"), it's discoverable regardless of this file and would risk
# showing up as a bare, snippet-less URL. /builder/ instead carries its
# own <meta name="robots" content="noindex, nofollow"> and stays crawlable
# so that tag actually gets read.
User-agent: *
Allow: /

# Explicit AI-crawler allows below are functionally redundant with the
# wildcard Allow above (nothing here is Disallow'd for anyone) - they're
# here because the goal isn't just "don't block AI" but "get cited by
# AI", and being explicit is the documented signal that a site actually
# wants these bots crawling it, per current (2026) GEO guidance. Covers
# both training crawlers (GPTBot, ClaudeBot, Google-Extended - what
# feeds a model's general knowledge) and the separate real-time
# answer/search crawlers (OAI-SearchBot, Claude-SearchBot,
# PerplexityBot - what a live query actually fetches at answer time).
User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: Claude-SearchBot
Allow: /

User-agent: Claude-User
Allow: /

Allow: /

User-agent: Perplexity-User
Allow: /
